# Plan: Implement Format-Specific Structural Mutators from Survey

**Date**: Based on survey.txt research
**Goal**: Add format-aware structural mutation operators for all FFmpeg target formats identified in the comprehensive survey at `docs/survey.txt`, extending the existing operator registry and mutation modules.

## Background

The survey at `docs/survey.txt` documents 656+ FFmpeg crash reproductions from OSS-Fuzz, per-CVE PoCs, and security advisories. The "How to Extract Op Mutators and Seeds" table maps each vulnerability to a format-specific seed field that an op mutator should target. The existing fuzzer already has format chunk mutators for PNG, JPEG, BMP, GIF, WebP, WebM, ISO-BMFF (MOV/MP4), RIFF (AVI), and others, but several formats from the survey lack dedicated mutators.

## Missing from survey targets (8 new mutators + 1 extension)

1. MagicYUV (AVI) — slice_height in stream header — `magicyuv_chunk_mutate`
2. JPEG2000 (.jp2) — cdef atom cn/asoc mapping, SIZ/COD/QCD markers — `jpeg2000_chunk_mutate`
3. AV1 over RTP — obu_size in OBU header (varint encoding) — `av1_rtp_chunk_mutate`
4. RASC (AVI) — DLTA run type + x/w/h coords — `rasc_chunk_mutate`
5. TIFF (.tif) — Strip size vs decompressed bytes — `tiff_chunk_mutate`
6. DVBSub (WTV) — Parse buffer size — `dvbsub_chunk_mutate`
7. CFHD — Tag order/multiplicity in CFHD chunks — `cfhd_chunk_mutate`
8. shorten (.shn) — Packet size in ffconcat — `shorten_chunk_mutate`
9. MOV/MP4 — ctts atom count fields (CVE-2022-2566) — extend `isobmff_chunk_mutate`

## Approach

Follow the exact pattern of existing format mutators (PNG/JPEG as templates):

### 1. Register in `operator_registry.py`
- Add operator name to `_CATEGORIES["format"]`
- Add sniffer function to `_FORMAT_SNIFFERS` dict
- `_format_available` auto-wires availability gating (format-aware bootstrap)

### 2. Create `src/fuzzer_tool/core/mutations/<name>.py`
- `<format>_mutator` class
- `parse_<format>()` function: validate format magic bytes
- `mutate()`: format-aware structural mutations
- `_generate_random_<format>()`: synthesize valid seed from scratch

### 3. Add `_op_<name>` handler on `OperatorEngine` (`services/operators.py`)
- Lazy-instantiate format mutator
- Call `parse_<format>()` to validate input
- If valid → `mutate()`, else → `_generate_random_<format>()`
- Return `bytearray(result[:max_len])`

### 4. Add forwarding `_op_<name>` on `Fuzzer` (`services/fuzzer.py`)
- Delegate to `self._operators._op_<name>`

## Mutators to Implement (8 new + 1 extension)

### A. `magicyuv_chunk_mutate` — MagicYUV AVI slice_height
- **Target**: AVI stream header `slice_height` field
- **Vulnerability**: CVE-2026-8461 — last slice sheight > height → OOB write
- **Fix pattern**: `dst + height * stride > buf_end` check before write loop
- **Sniffer**: Check for AVI RIFF header + MagicYUV fourcc (`BMH5`/`BMH6`)
- **Mutation**: Corrupt `slice_height` to create uneven remainders (e.g., 31 for 640-wide frames)

### B. `jpeg2000_chunk_mutate` — JPEG2000 codestream markers
- **Target**: JPEG2000 SIZ/COD/QCD/cdef markers
- **Vulnerability**: CVE-2025-9951 — cdef cn/asoc mapping mismatch → OOB write
- **Fix pattern**: Validate component resolution matches channel mapping
- **Sniffer**: Check for JP2 signature (`\x00\x00\x00\x0cjP\x0d\x0a\x87\x0a`) or SOD marker
- **Mutation**: Corrupt component mapping entries, cdef asoc values, SIZ dimensions

### C. `av1_rtp_chunk_mutate` — AV1 over RTP OBU header
- **Target**: OBU size varint encoding in AV1 bitstream
- **Vulnerability**: DFVULN-127 — TD-skip advances cursor without allocating
- **Fix pattern**: Advance buf_ptr alongside pktpos
- **Sniffer**: Check for AV1 start code (`0x00 0x00 0x01`) or OBU byte 0 type bits
- **Mutation**: Corrupt obu_size varint; test TD-skip path edge cases

### D. `rasc_chunk_mutate` — RASC AVI DLTA run type + x/w/h coords
- **Target**: RASC INIT/DLTA chunk structure
- **Vulnerability**: 32-bit write crosses 64-byte row boundary
- **Fix pattern**: Check cx + 4 <= w * bpp before 32-bit access
- **Sniffer**: Check for AVI RIFF header + RASC codec (`RASC`)
- **Mutation**: Corrupt DLTA run-type byte, x/y/w/h coordinates

### E. `tiff_chunk_mutate` — TIFF strip size
- **Target**: Strip size vs decompressed bytes
- **Vulnerability**: CVE-2026-70631 — memcpy copies all rows regardless of zlib output
- **Fix pattern**: Check zlib decompressed size before memcpy
- **Sniffer**: Check for TIFF header (`II*\x00`/`MM\x00*`)
- **Mutation**: Corrupt StripByteCounts/StripOffsets to mismatch decompressed size

### F. `dvbsub_chunk_mutate` — DVBSub WTV parse buffer size
- **Target**: DVBSub parse buffer size in dvbsub_parser.c
- **Vulnerability**: CVE-2026-70628 — signed integer overflow wraps guard
- **Fix pattern**: Check for negative/wrapped parse_offset
- **Sniffer**: Check for WTV/EBML header + DVBSub codec
- **Mutation**: Corrupt buffer size/offset fields to trigger signed integer wrap

### G. `cfhd_chunk_mutate` — CFHD chunk tag order/multiplicity
- **Target**: CFHD chunk tags and tag multiplicity
- **Vulnerability**: Multiple CVEs — SEGV, OOM, null deref, left shift
- **Fix pattern**: Validate tag order/multiplicity per spec
- **Sniffer**: Check CFHD magic bytes and chunk structure
- **Mutation**: Corrupt chunk tag ordering, insert/delete tags, vary multiplicity

### H. `shorten_chunk_mutate` — shorten (.shn) packet size in ffconcat
- **Target**: Packet size in ffconcat
- **Vulnerability**: CVE-2026-65704 — size decrement wraps to near-SIZE_MAX
- **Fix pattern**: Bounds-check size before memcpy
- **Sniffer**: Check for shorten magic/extension
- **Mutation**: Corrupt packet size fields to trigger underflow

### I. `isobmff_chunk_mutate` — Extend for MOV/MP4 ctts atom count fields
- **Target**: ctts atom sample_count/sample_offset fields
- **Vulnerability**: CVE-2022-2566 — integer overflow in sample_offsets_count
- **Fix pattern**: Add overflow check before av_calloc
- **Mutation**: Corrupt ctts entry count and offset values to trigger integer overflow
